# SYC React College Recruitment — v9

v9 is a visual-spatial polish pass on the v8 design.

### Changes
- Removes the heavy full-block feel from **Why Join SYC** and replaces it with a lighter editorial section.
- Adds subtle side labels, a rhythm strip, department list helper text, and a large department watermark to distribute visual weight.
- Adds a small pre-CTA statement strip so the page has breathing room instead of ending in a dense cluster.
- Anchors the final CTA content to the lower-left while **keeping the existing CTA image unchanged**.
- Keeps the dynamic five-department image panel, fallback image handling, separate recruitment page, user-edited wording, and current supplied hero image.

## Run

```bash
npm install
npm run dev
```
